# new-issue

GitHub 이슈를 생성합니다.

## 프로세스

1. 사용자에게 아래 정보를 수집합니다:
   - 이슈 제목
   - 타입: `feat` / `fix` / `chore` / `docs` / `refactor`
   - 작업 내용 (어떤 화면/컴포넌트를 만들거나 수정하는지)

2. 아래 형식으로 이슈 본문을 작성합니다:

```
## 개요
(한 줄 요약)

## 작업 내용
- [ ] 항목 1
- [ ] 항목 2

## 관련 화면 / 컴포넌트
(해당하는 경우 기재)

## 참고 사항
(API 엔드포인트, 타입 정보 등)
```

3. `mcp__github__create_issue` 툴로 `DGU-CAP/frontend` 레포에 이슈를 생성합니다.
   - labels: 타입과 동일하게 지정

4. 생성 후 브랜치 명 안내:
   - 형식: `<type>/#<이슈번호>-<간단한-설명>`
   - 예시: `feat/#6-dashboard-page`
   - 이후 `/new-pr` 명령어로 PR을 생성할 수 있다고 안내합니다.
